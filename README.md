# Build From Skeleton

This project is built starting from a skeleton template.

## Getting Started

### Prerequisites
- Python 3.x

### Setup Virtual Environment
A virtual environment has been created in the `venv` directory. To activate it:

**On Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

**On Windows (Command Prompt):**
```cmd
.\venv\Scripts\activate.bat
```

**On macOS/Linux:**
```bash
source venv/bin/activate
```
