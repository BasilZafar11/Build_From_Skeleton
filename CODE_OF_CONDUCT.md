# Code of conduct

Everyone participating in Build From Skeleton should be able to ask questions,
learn, and contribute without harassment. This applies to issues, pull requests,
discussions, and other spaces officially maintained for this project.

## Expected behavior

- Discuss the work respectfully and explain technical disagreements.
- Welcome questions from people with different experience levels.
- Give actionable feedback and accept corrections.
- Respect people's identities, boundaries, time, and privacy.

Harassment, discrimination, threats, sexual harassment, personal attacks, spam,
and publishing another person's private information without permission are not
acceptable. Repeated unwanted contact is also unacceptable.

## Reporting

**Private reporting directly to the project maintainer is not configured yet.**
Basil will add a monitored contact before broad community promotion. Do not post
private details in a public issue or PR.

For abuse on GitHub, use GitHub's existing
[abuse-reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Those reports go to GitHub, not directly to this project's maintainer. GitHub
handles those reports under its own policies. For ordinary, non-sensitive
moderation requests, mention [@BasilZafar11](https://github.com/BasilZafar11) in
the relevant thread.

## Enforcement

The maintainer reviews project conduct concerns in context and may ask someone
to edit a comment, issue a warning, remove disruptive content, temporarily limit
participation, or exclude someone from the project. The response should reflect
the severity and recurrence of the behavior. Serious threats or harassment may
warrant immediate exclusion.

People should have an opportunity to explain a misunderstanding when practical.
Once a private reporting contact exists, it can also be used to request review
of a moderation decision. There is currently one maintainer, so independent
appeal review is not available. No response-time guarantee is made.
